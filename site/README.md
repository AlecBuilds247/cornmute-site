# cornmute-site

Public website for the CornMute Chrome extension (GitHub Pages).

- `index.html` – home page
- `privacy.html` – privacy policy (use this URL in the Chrome Web Store listing)
- `demo.html` – harmless test-tone page for reviewers

Upload all files in this folder to the root of the `cornmute-site` repo, then Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
